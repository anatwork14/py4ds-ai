# Notebooks

Use this directory for **new, optional exploratory notebooks** that call the maintained modules from `src/py4ds_ai/` and do not mutate original data.

The original, output-heavy assignment notebook has been preserved as [legacy/notebooks/main.ipynb](../legacy/notebooks/main.ipynb) along with the old feature arrays and PDF. Those archived outputs reflect an earlier protocol and should not be treated as the results of the maintained pipeline.

For current evaluation results see [FINAL_REPORT.md](../docs/FINAL_REPORT.md). Never rerun the sealed test evaluation through a notebook.
