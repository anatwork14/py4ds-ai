2. **Protect the original data.** Never delete or move original Kaggle files during cleaning or splitting. In particular do NOT remove seg_pred. Treat raw data as read-only; use manifests/indices or derived directories to control training.
3. **Preserve the original held-out test.** The dataset's seg_test is final evaluation only. Take a deterministic, stratified validation split from seg_train (proposed 15%, seed 42); make a durable CSV manifest recording relative path, split, label, hash, source, and exclusions. Don't choose hyperparameters, cleaning thresholds, checkpoints, normalization values, or augmentation settings by comparing test scores.
4. **Leakage is a release blocker.** Any trainable preprocessing step (normalization statistics, StandardScaler, PCA, visual vocabulary MiniBatchKMeans, feature selection, label-dependent encoding) must be fitted on training data only, or independently within the training fold when doing cross-validation. Validate no identity/near-duplicate leakage across splits; report and adjudicate conflicts without altering raw data. If cross-split duplicates are found, preferentially exclude conflicting training/validation examples, preserving the defined test benchmark and documenting exclusions.
5. **Handle image quality deliberately.** Detect unreadable/zero-byte files, unexpected channels/modes, dimensions, exact hashes, and perceptual near-duplicates. Convert valid images to RGB; resize/crop at model input. Do not silently drop every image that is not 150×150 or square; quantify and justify any exclusion. A perceptual-hash match is a review flag, not proof two differently labeled scenes are identical.
6. **Reproduce experiments.** Seed random, NumPy, PyTorch and DataLoader workers; document limits of deterministic GPU operations. Record Python/package versions, OS, device, dataset fingerprint, source commit SHA, seed, effective configurations, runtime, predictions and checkpoints. Use a versioned requirements/lock strategy.
7. **Clear provenance.** Cached features require a manifest mapping each row to image ID/path and label, and recording model weights version, transform, split hash, dtype, and seed. Never reuse stale caches with different preprocessing.
8. **No silent failures.** Raise useful errors for missing data, label mismatch, corrupt images, empty split, shape/dtype/device mismatch, failed download, or absent pretrained weights. Assertions validate split disjointness, expected class ordering, count conservation and prediction lengths. Use unit and smoke tests; avoid broad exceptions that silently skip failures.
9. **Keep outputs auditable.** Commit source, configs, test code, report text, plots definitions and lightweight metrics only. Exclude Kaggle images, raw datasets, model checkpoints and large generated feature arrays from Git, with explicit documented paths.
10. **Respect source provenance and licenses.** State the Kaggle dataset URL, original Intel challenge attribution only where verifiable, date/version of the downloaded dataset, and applicable license/terms after inspecting the source. Do not assert that rehosting confers unrestricted reuse.

## Scope: models that must actually be compared

A. Majority-class or stratified random baseline, using no visual signal; evaluate on validation only. The held-out test was already scored once for the frozen selected CNN, and must never be scored again.

B. **Classical ML:** HOG + StandardScaler + optional PCA + LinearSVC; SIFT + Bag of Visual Words + LinearSVC or LogisticRegression. Implement feature-extractor interfaces with deterministic output and training-only fitting for codebook/PCA/scaler. Add a meaningful hyperparameter grid (e.g., SVM C, PCA components, vocabulary size) evaluated on train-validation only. Include clear preprocessing and engineered-feature visualizations.

C. **Hybrid:** ImageNet-pretrained ResNet18, frozen and used as a deterministic 512-dimensional feature extractor, then StandardScaler (if appropriate) + LogisticRegression / LinearSVC tuned on validation. Record the pretrained weight identifier and input transformation. Frozen feature extraction must not use stochastic training augmentation if embeddings will be cached and compared.

D. **Deep learning:** train a modest CNN from scratch (optional if time/compute constrained, clearly identified) and at minimum train an ImageNet-pretrained ResNet18 with (1) frozen backbone / trainable classification head and (2) optional unfreezing of the last block for a controlled fine-tuning experiment. For the minimum viable submission, prioritize **A+B+C and one trained end-to-end DL ResNet18**. Clearly distinguish "pretrained feature extractor + SVM" from "fine-tuned CNN"; they are not interchangeable experiments.

Use PyTorch/torchvision as the primary DL stack, consistent with the course; scikit-learn, NumPy, Pandas, Matplotlib/Seaborn, and OpenCV for classical features. Avoid introducing unnecessary TensorFlow and new orchestration frameworks.

## Image preprocessing

- Classical grayscale HOG/SIFT may use a stable resize and explicitly documented normalization.
- Pretrained ResNet18 must use its *weight-specific* documented inference preprocessing for deterministic embeddings/validation/test (e.g., ResNet18_Weights.IMAGENET1K_V1.transforms()). Create appropriate compatible TRAIN augmentation while preserving its expected normalization. Never silently substitute dataset-derived mean/std for ImageNet normalization in a pretrained model. Resize/crop choice is an experimental variable, not an invisible tweak.
- Keep transforms separate: train augmentation only in train loaders, deterministic val/test transforms elsewhere. Do not perform random flips during feature cache creation.
- Use torch.inference_mode() for embedding extraction and evaluation, model.eval() for inference and model.train() for training. For optimization: optimizer.zero_grad(set_to_none=True), forward, CrossEntropyLoss, backward, optimizer.step; measure loss weighted by batch size. Save best validation checkpoint and record early stopping.

## Evaluation contract

- Choose hyperparameters and early-stopping epoch using train/validation only; test once after selections are frozen.
- Output per-model train and validation details. Final test metrics (accuracy, macro-F1, weighted-F1, per-class precision/recall/F1/support, confusion matrices and timing) exist **only for the previously frozen and evaluated winner**; all unselected models keep NOT RUN test status. Never run the final evaluator again for the existing manifest.

- Compare accuracy versus computation and error patterns, not just top score. Distinguish measured Intel dataset performance from published ImageNet results. No accuracy is a target to fabricate or "hit."
- Run confidence intervals or repeated seeds when compute permits; if only one run, disclose the limitation.
